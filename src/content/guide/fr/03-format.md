Dans **Format**, chaque catégorie a son propre format : une suite de **phases**. Le plus simple est de cliquer sur **Partir d'un preset…** et de choisir un format prêt à l'emploi, par exemple :

- **Poules uniquement** ;
- **Poules + tableau principal** ;
- **Poules + principal + consolante** ;
- **Tableau à placement complet**, en élimination directe dès le tirage.

Vous pouvez aussi construire le format vous-même :

- **une phase de poules** : tailles de poule par ordre de préférence (par exemple 4, sinon 5) ou nombre fixe de poules, ordre de départage, comparaison entre poules ;
- **un tableau** : élimination directe, avec **toutes les places jouées** (placement complet) ou des ex aequo par tour perdu ;
- **le routage** : quels rangs de quelle phase vont dans quelle phase suivante (les rangs 1 à 3, les meilleurs 4es, le reste…) ;
- **la condition de victoire** de chaque phase : sets gagnants, points par set, plafond de points, ou match au temps avec point en or, et la durée estimée sur le terrain qui sert à l'échéancier.

Sous l'éditeur, la simulation montre pour votre nombre d'inscrits les poules, le nombre de matchs, de tours et les places jouées. Un format qui vous plaît s'enregistre comme preset, réutilisable dans vos prochains tournois.

> Les matchs au temps se jouent par rotations : tous les terrains commencent et finissent ensemble. Ils ne sont possibles que lorsqu'une seule catégorie joue.

Le format reste modifiable jusqu'au premier match appelé ou joué dans la catégorie.
